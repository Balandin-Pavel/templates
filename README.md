# generator — утилита-шаблонизатор

Консольная утилита для генерации текстовых документов на основе шаблона и файла с данными. Заменяет плейсхолдеры вида `{{ variable_name }}` в шаблоне на значения переменных, заданные в отдельном файле.

Реализовано на C++ без использования STL-контейнеров, `std::string` и `std::regex` — только стандартная библиотека ввода/вывода.

## Возможности

- Подстановка меток `{{ variable_name }}` значениями из файла данных.
- Поддержка пробелов внутри фигурных скобок: `{{name}}`, `{{ name }}`, `{{  name  }}` — эквивалентны.
- Парсинг файла данных в формате `KEY=VALUE`, одна пара на строку.
- Игнорирование ведущих/завершающих пробелов и пробелов вокруг `=`.
- Поддержка комментариев в файле данных (строки, начинающиеся с `#` или `//`).
- При повторном определении ключа используется последнее значение.
- Вывод результата в файл или в стандартный поток вывода.
- Диагностика ошибок через коды возврата.

## Ограничения формата данных

| Параметр | Значение |
|---|---|
| Допустимые символы ключа/значения | латиница, цифры, `_` |
| Ключ и значение | одно слово (без пробелов) |
| Максимальная длина ключа/значения | 100 символов |
| Максимальное число пар | 1024 |

## Сборка

```
cmake -S . -B build
cmake --build build --target generator
```

## Использование

```
generator --template=path --data=path [--output=path]
```

| Короткий флаг | Длинный флаг | Обязательный | Описание |
|---|---|:---:|---|
| `-t path` | `--template=path` | ✅ | Путь к файлу-шаблону |
| `-d path` | `--data=path` | ✅ | Путь к файлу с данными |
| `-o path` | `--output=path` | ❌ | Путь к результирующему файлу (по умолчанию — stdout) |

### Пример

```
generator --template=template.txt --data=data.dat --output=output.txt
```

Пример входных и выходных файлов — в директории [`example`](example).

## Коды возврата

| Код | Значение |
|---|---|
| 0 | успешное завершение |
| 1 | в шаблоне есть метка без соответствующего ключа в данных |
| 2 | ошибка аргументов командной строки |
| 3 | ошибка ввода-вывода |
| 4 | синтаксическая ошибка в шаблоне (незакрытая метка, некорректные скобки) |
| 5 | прочие ошибки |
